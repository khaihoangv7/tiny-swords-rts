# Tiny Swords RTS

A lightweight 2D real-time strategy game built with Unity and C#,
featuring resource management, base building, unit production,
and tactical combat.

## Tech Stack

- Unity
- C#
- Git / GitHub

## Features

- Resource gathering
- Worker management
- Base building
- Unit production
- RTS unit selection and movement
- Counter-based combat
- Enemy AI
